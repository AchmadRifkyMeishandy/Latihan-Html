# Latihan HTML dan CSS

Kumpulan latihan awal untuk memahami pembuatan halaman web, struktur HTML, styling dengan CSS, dan sedikit interaksi JavaScript.

## Isi Repository

- Struktur dasar dokumen HTML.
- Paragraf, entitas HTML, penekanan teks, dan daftar.
- Tautan serta navigasi antarhalaman.
- Tabel dan formulir.
- Latihan CSS.
- Contoh website sederhana dengan halaman beranda, tentang, dan kontak.

## Teknologi

- HTML
- CSS
- JavaScript dasar pada contoh tertentu
- Web browser dan Visual Studio Code

## Menjalankan

Tidak memerlukan database atau proses build. Buka file `index.html` atau halaman latihan lain melalui browser. Untuk mempermudah pengembangan, folder dapat dibuka di Visual Studio Code dan dijalankan dengan Live Server.

Repository ini menjadi arsip latihan frontend dari dasar dan membantu memahami hubungan antara struktur HTML, tampilan CSS, dan interaksi JavaScript.
